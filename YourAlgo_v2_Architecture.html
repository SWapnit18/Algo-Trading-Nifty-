3. Recommended Core Intraday Algorithm

Recommendation: Do not rely on uninterpretable black-box ML models for primary order execution. Start with a deterministic, mathematically backtested Trend Following + Momentum + Volume Confirmation strategy:

AUTOMATIC BUY SIGNAL

A Long Entry order is triggered only when all 8 conditions are met simultaneously:

  • EMA Crossover: EMA(20) > EMA(50)
  • Value Anchor: Close Price > VWAP
  • Momentum: RSI(14) > 50.0
  • Volume Confirmation: Volume > 20-bar Average Volume
  • Position Guard: No existing open position in the instrument
  • Account Guard: Daily cumulative loss < Max Loss Limit
  • Feed Status: Market feed is verified LIVE
  • Risk Validation: validate_trade() approved by Risk Engine

AUTOMATIC SELL / EXIT

An immediate square-off market order is sent upon any of the following triggers:

  • Target Hit: Price reaches Entry + (Risk Distance × 3)
  • Stop Loss Hit: Price touches ATR-based Stop Loss level
  • Trend Invalidation: EMA(20) crosses below EMA(50) or Close < VWAP
  • EOD Square-Off: Time reaches 15:15 IST (Intraday MIS cutoff)
  • Emergency Exit: Global Kill Switch triggered by trader or risk breach

4. Mathematical Risk Engine & Position Sizing

The frontend interface must never decide trade quantities. The server-side Risk Engine dynamically calculates the exact number of shares based on current market volatility (ATR) and fixed account equity risk:

Risk Amount (₹) = Account Equity × Risk Percentage (1%)
Stop Loss Distance (₹) = 1.5 × ATR(14)
Calculated Quantity = floor( Risk Amount ÷ Stop Loss Distance )
Target Price (₹) = Entry Price + ( 3.0 × Stop Loss Distance ) [1:3 Risk/Reward]

Worked Example:

Parameter Numerical Value Explanation
Account Equity ₹1,00,000 Current available liquid trading capital
Risk per Trade 1.0% (₹1,000) Maximum loss allowed if Stop Loss is hit
Stock Entry Price ₹1,000.00 Current LTP at signal generation
ATR(14) Volatility ₹12.00 Average True Range over past 14 fifteen-minute candles
Stop Distance ₹18.00 (1.5 × ₹12) Volatility-adapted dynamic stop buffer
Stop Loss Price ₹982.00 1,000.00 - 18.00
Target Price (1:3 RR) ₹1,054.00 1,000.00 + (3 × 18.00) = ₹54 profit per share
Order Quantity 55 shares floor( ₹1,000 ÷ ₹18 ) = 55 shares (Total max risk = ₹990.00)
